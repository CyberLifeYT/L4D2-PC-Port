Shader cache

New effects stutter the first time they appear while their shaders compile. Build the cache once (about 1–2 minutes per map) and play-throughs stay smooth.

Install

Select your Left 4 Dead 2 Xbox 360 disc image. The launcher extracts the game files, then installs the PC port patch on top.

Settings

Saved to l4d2_settings.ini in the install folder and applied when the game starts. Most can also be changed live in game with F4.

Controls

PC keyboard & mouse bindings. Click + and press a key, mouse button or roll the wheel to add it; click a key to remove it. Mouse sensitivity and invert are on the Settings page.

Reserved keys

F2 (performance overlay), F3 and ` (debug overlay / console), F4 (live settings) and F12 (screenshot) are used by the port and can't be bound.

Mods

Loose-file mods load before the game's own files. Each mod is a folder laid out like left4dead2 (materials, models, scripts, sound, maps, resource) or a zip0.360.zip pack. Higher in the list wins. A mod.json can add settings (sliders, toggles) and game console commands - start from the FOV Changer starter mod.

Compatibility

This is the Xbox 360 build of the engine. PC .vpk addons are unpacked into loose files when you add them: scripts, configs, text, VScripts and 360-built maps work. PC-format models, textures and sounds (.mdl/.vtf/.wav) generally need their 360 versions (.360.mdl/.360.vtf/.360.wav). Changes apply the next time you press Launch.

Updates

Port fixes ship as patch files. Installing a patch keeps your settings and backs up the previous version.

About

An unofficial PC port of the Xbox 360 version of Left 4 Dead 2, built by statically recompiling the game's PowerPC code to x86-64 with the ReXGlue toolchain.

Your disc, your files

No game data is distributed with this launcher or its patches. You need your own Left 4 Dead 2 Xbox 360 disc image; the port loads the game's assets from the files extracted from it.
